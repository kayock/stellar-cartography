# Receipts — work in progress

There is **no current R0.5.0 release receipt** in this working tree.

The preserved R0.4.0 baseline lives under:

`receipts/baseline_r0.4.0/`

Those files describe the frozen R0.4.0 release only. They must not be read
as describing R0.5.0 development or as a checksum manifest of this tree.

A new, uniquely versioned R0.5.0 receipt and `SHA256SUMS` will be created
only at final packaging — never by overwriting the R0.4.0 baseline.
