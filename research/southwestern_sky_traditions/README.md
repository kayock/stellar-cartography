# Southwestern sky traditions — research workspace

This folder is a **research pack**. It is not a story library.

Cartography implements a cultural sky story only when a dossier
scorecard marks it **READY**. Restricted, seasonal-only, generic
pan-Indigenous, or weakly sourced material stays here as
`DEFER` / `RESTRICTED`.

## Traditions researched separately

| Dossier | People / context | Implementation this pass |
|---|---|---|
| `dine.md` | Diné / Navajo | none — seasonal / ceremonial restriction |
| `apache.md` | Apache communities distinguished | none — ceremonial or insufficient |
| `pueblo.md` | Hopi, Zuni, Acoma, Taos, other Pueblos | none — no specific-community READY card |
| `ancestral_puebloan.md` | Ancestral Puebloan archaeoastronomy | 2 READY cards |
| `mexica.md` | Historical Mexica / Nahua colonial sources | 2 READY cards |

## Rules used

- No generic “Native American mythology.”
- No merging of Apache bands or Pueblo nations.
- Ancestral Puebloan is archaeological, not a living oral story.
- “Anasazi” is a search alias only; display is Ancestral Puebloan.
- Similar motifs are recorded as `independent_similarity` unless a
  cited source argues exchange.
- Sacred, ceremonial, seasonal-only, or restricted material is not
  copied into stories or into these notes beyond the exclusion reason.

See `REPORT.md` for the scorecard and `source_matrix.json` for sources.
